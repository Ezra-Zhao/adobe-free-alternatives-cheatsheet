# Alternativas grátis ao Adobe — cola em uma página

> 📌 Esta tabela é uma compilação de informações públicas e é atualizada todo mês; PRs são bem-vindos.
>
> 🌍 [中文](README.md) · [Español](README.es.md)

Cansado de pagar a assinatura da Adobe? Esta cola reúne, em uma página, a alternativa grátis ou open source de cada programa da Adobe: o que faz, em quais plataformas roda, como instalar e onde fica o site oficial.

## A cola

👉 **[CHEATSHEET.md](CHEATSHEET.md)** ——trilíngue（中文 / Español / Português）, com as 16 alternativas.

## Por que esta tabela existe

Em outubro de 2026, o GitHub viveu um fenômeno: a equipe [storytold](https://github.com/storytold) reescreveu do zero, em Rust, a suíte inteira da Adobe——PhotoCraft（Photoshop）、VectorCraft（Illustrator）、FilmCraft（Premiere）、LightCraft（Lightroom）、PrintCraft（Acrobat）、EffectCraft（After Effects） e DesignCraft（InDesign）. Os sete apps explodiram no trending global do GitHub no mesmo dia, e o PhotoCraft ganhou mais de 10 mil estrelas em 24 horas. Some veteranos do open source como GIMP, Inkscape, DaVinci Resolve e Blender, e pela primeira vez um fluxo criativo completo custa zero.

Esta tabela ajuda você a achá-los em uma página.

## O que está incluído

- **As 7 do ArtCraft**（da storytold, reescritas em Rust; alpha inicial, para curiosos）
- **9 alternativas maduras**：GIMP、Inkscape、DaVinci Resolve、Kdenlive、darktable、Audacity、Blender、Penpot、Scribus
- Cada entrada：nome → uma frase → plataformas → preço → um comando de instalação → site oficial

## Contribuir

Conhece uma alternativa melhor, um link quebrado ou um comando desatualizado? Abra um PR：

1. Faça fork do repositório
2. Atualize a mesma entrada nas três seções de idioma do `CHEATSHEET.md`（mantenha os três idiomas sincronizados）
3. Envie o PR explicando o que mudou e de onde veio a informação

Todo mês faço uma atualização geral（versões, ferramentas novas, limpeza de links）。
