¿Harto de pagar la suscripción de Adobe? Esta chuleta reúne, en una sola página, la alternativa gratis o open source de cada programa de Adobe: qué hace, en qué plataformas corre, cómo se instala y dónde está su web oficial.

## La chuleta

👉 **[CHEATSHEET.md](CHEATSHEET.md)** ——trilingüe（中文 / Español / Português）, con las 16 alternativas.

## Por qué existe esta tabla

En octubre de 2026, GitHub vivió un fenómeno: el equipo de [storytold](https://github.com/storytold) reescribió desde cero, en Rust, toda la suite de Adobe——PhotoCraft（Photoshop）、VectorCraft（Illustrator）、FilmCraft（Premiere）、LightCraft（Lightroom）、PrintCraft（Acrobat）、EffectCraft（After Effects） y DesignCraft（InDesign）. Las siete apps reventaron el trending global de GitHub el mismo día, y PhotoCraft ganó más de 10.000 estrellas en 24 horas. Súmale veteranos del open source como GIMP, Inkscape, DaVinci Resolve o Blender, y por primera vez un flujo creativo completo cuesta cero.

Esta tabla te ayuda a encontrarlos en una sola página.

## Qué incluye

- **Las 7 de ArtCraft**（de storytold, reescritas en Rust; alpha temprana, para curiosos）
- **9 alternativas maduras**：GIMP、Inkscape、DaVinci Resolve、Kdenlive、darktable、Audacity、Blender、Penpot、Scribus
- Cada entrada：nombre → una frase → plataformas → precio → un comando de instalación → web oficial

## Contribuir

¿Conoces una alternativa mejor, un enlace roto o un comando desactualizado? Abre un PR：

1. Haz fork del repositorio
2. Actualiza la misma entrada en las tres secciones de idioma de `CHEATSHEET.md`（mantén los tres idiomas sincronizados）
3. Envía el PR explicando qué cambiaste y de dónde sale la información

Cada mes hago una actualización general（versiones, herramientas nuevas, limpieza de enlaces）。
